comment
  The shared page: what every target has (the data words, bits, rel), the targets as sections, and the choice of one of them by --target. Operands go in the reverse order of GNU as, the destination last, as in the instructions.
  Every name ttpc takes by itself, the builtins of asm and the words of C, declared like any function so that each is defined before it is called. ttpc takes these calls itself: the declarations are never run.
  In asm a C word is a function with an empty body: a stray if expands to nothing (a wrong number of arguments still dies).
  comment text: a comment, anywhere (code, assemble time, C, beside definitions, among the fields of an encoding); its text is never evaluated.
  license spdx notice: a license, the SPDX expression (GPL-3.0-only, LGPL-2.1-or-later), then the notice, a line per child after it (a line over 255 bytes goes on in the next).
  To ttpc a license is a comment, anywhere one may stand; make licenses checks that every tree has one, with a known SPDX id.

comment
  line file number: C, where the statements after it come from in the C the tree was made from, as c2ff writes it from clang's places (C's #line N "file"); line number alone is in the file of the line before it.
  It makes no code, as a comment; in a C function it stands where a statement does, the first one after the function's head (its comment) naming the file.
  With -g the line table has the C file and line of the code of those statements (the C view); where a tree has none, the line of each node in the tree's text (the ff view).
